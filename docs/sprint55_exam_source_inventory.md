## 4. 盤點方法與限制

- PDF：使用 `scripts/sprint55-pdf-metadata.py` 與 `pypdf` 讀取頁數、可抽取文字、PDF image objects，並以文字與 JSON 題幹做 exact normalized match。
- DOCX／DOC：使用 Word read-only automation；DOCX 讀取頁數與 shapes，legacy DOC 的 layout 統計若不穩定則保留 `未取得`。
- 本次執行環境未能啟動 Word COM；DOCX／DOC 保留檔案、hash 與分類，但文字、頁數、圖片及題數估算列為未取得；詳細原因見讀取錯誤。
- PPT／PPTX：使用 PowerPoint read-only automation；以投影片數、圖片 shapes 與文字估算。
- XLS／XLSX：保留檔案級 metadata、hash 與分類，不啟動 Excel 或展開工作簿內容，以避免相容性檔案阻塞整體盤點。
- RTF、Pages、textClipping 與獨立圖片：只做檔案與可讀文字盤點；無法安全推定頁數或題數時標示 `未取得`。
- `已進入 JSON 題庫` 只表示文件全文包含 normalized JSON 題幹；不代表 source page、答案、版本或 reviewer decision 已完成。
- 管理型目錄 `04_整理報告`、`05_題庫候選`、`06_題庫報告` 共 28 份未列入 source-like 文件表，避免把盤點報告或候選 JSON 當成原始考試來源；其檔案數已在總結列出。
